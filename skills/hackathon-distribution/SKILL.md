# Hackathon distribution

Distribution decides outcomes as much as code. Adapted from Joseph's private distribution-playbook (import its `distribution-first-strategy`, `platform-growth-playbooks`, `taste-over-slop` and `brand-voice-and-authentic-ai-writing` skills with scripts/import-skills.sh for the full method).

## Channels (owned first)
X (main), LinkedIn (linkedin.com/in/josephc9), Colosseum build logs, Solana/x402 Discords and Telegram groups, GitHub README.

## Cadence D3–D10
- One proof post per day: a real artifact (402 curl output, first devnet tx signature, dashboard screenshot, Claude paying on video). Format: what shipped, the proof, what is next.
- D7 launch thread: problem → 30 s clip → how it works (3 bullets) → repo link → ask (try it / star / feedback).
- Colosseum build log entry each time a ROADMAP slice ships.
- Tag x402, Solana, PayAI, Colosseum only when the post is about their tech.

## Voice rules
Specific numbers, real screenshots, no hype words, no "revolutionary", no thread-bait. One idea per post. Show the tx signature.

## Gates
Drafts go to `docs/launch/`. Joseph approves and posts. Never DM strangers in bulk.
