# Decisions log

| Date | Decision | Why | Alternatives considered |
|---|---|---|---|
| 2026-10-02 | Rust gateway is the primary build; Cloudflare Worker is a second edition | Performance, single binary, Website Factory VPS hosting; Worker covers Cloudflare users | Worker-only (locks to Cloudflare), Node proxy (slower, less differentiated) |
| 2026-10-02 | Solana primary, Base secondary | Colosseum Solana track; Solana leads weekly x402 volume (KB-MKT-01); Base has mature EVM x402 tooling | Solana only, Base only |
| 2026-10-02 | Default detection mode `agents-only` | Humans must never see a paywall; spoofed bot UAs only get a price quote | Charge all requests |
| 2026-10-02 | Settle only after origin 2xx | Agents should not pay for errors; builds trust | Settle before forwarding |
| 2026-10-02 | Non-custodial: funds go straight to founder `payTo` | No money-transmitter risk; simpler trust story | Pooled account with payouts |
| 2026-10-02 | Gateway calls the facilitator `/verify` + `/settle` directly with hand-rolled v2 serde types; `x402-axum` is not used in the gateway | `x402-axum` dynamic pricing sees only headers + URI, not method or body, so it cannot price MCP `tools/call` (KB-X402-03). x402-types v2 response types lag the spec (`settlement_pending`, `amount`, `extensions`). The surface is ~6 structs + 3 HTTP calls | (a) x402-axum layers per route; (b) depend on x402-types for request structs only, still open if hand-rolled structs drift |
| 2026-10-02 | Canonical x402 spec source is x402-foundation/x402 | coinbase/x402 README declares itself a development fork of the foundation repo | Keep citing coinbase/x402 |
| 2026-10-02 | Pricer canonicalizes paths (percent-decode, collapse `//`, resolve `..`, drop trailing `/`) before matching | Otherwise `/api/%71uote` falls through a priced route into the free `/*` catch-all | Match raw paths |
| 2026-10-02 | Malformed MCP bodies are rejected (400), not forwarded free | An origin with a lenient JSON parser could run a paid tool the pricer could not see | Forward free and let the origin error |
| 2026-10-02 | Heuristic agent verdicts (curl, headless, missing browser headers) are logged but never charged in `agents-only` mode | Bias to human; only self-declared or verified agents pay. Heuristics feed the "traffic you are not billing yet" report | Charge heuristics at low confidence |
| 2026-10-02 | Prices are quoted decimal strings in YAML (`"0.002"`); bare numbers are rejected | YAML numbers parse as floats; the money path is integer-only (KB-AMT-01) | Accept floats and round |
| 2026-10-02 | Route globs match case-insensitively; normalizer also drops `?query`, `;params` and reads `\` as `/` | Critic D1 risks 1-3: Express/IIS route case-insensitively and servlet containers ignore `;params`, so `/API/quote` or `/api/quote;x=1` would otherwise price cheaper. Over-pricing is harmless because settlement follows origin 2xx | Case-sensitive raw match |
| 2026-10-02 | Gateway sends the origin its own Host by default (`preserve_host: false`); client Host goes in `X-Forwarded-Host` | Hosted origins (Vercel, Netlify) route by Host; D7 deploys in front of one | Preserve Host by default (skill text) |
| 2026-10-02 | Solana `feePayer` is read from the facilitator's `/supported` at startup, overridable per network with `fee_payer` | It differs per facilitator (KB-X402-04); hardcoding breaks when switching facilitators | Hardcode PayAI's fee payer |
| 2026-10-02 | Until D3, a request carrying `PAYMENT-SIGNATURE` on a priced route gets 402 with an explicit error and is never forwarded; v1 `X-PAYMENT` gets a v2-only error | Never forward an unverified payment to the origin | Forward and trust the header |
| 2026-10-02 | Solana devnet stays the primary network; Base Sepolia is a live backup rail for recording | Colosseum is a Solana accelerator and the Solana track only counts Solana projects (KB-HACK-01); Solana leads x402 volume (KB-MKT-01). The gateway has no chain-specific money logic (the facilitator does the chain work), so Base costs little and de-risks a flaky devnet on camera | Switch to Base Sepolia only; add more chains |
| 2026-10-02 | The facilitator is always sent the gateway's own quote; the client's echoed `accepted` must match it on scheme, amount, asset and payTo or the request is refused before `/verify` | A client-supplied quote could name a cheaper amount or its own wallet | Trust `accepted` and let the facilitator check |
| 2026-10-02 | Paid origin responses are buffered (16 MiB cap) and released only after `/settle` succeeds | x402 MCP transport rule: content must not be returned if settlement fails; same for HTTP so agents cannot keep unpaid content | Stream first, settle after (content leaks on settle failure) |
| 2026-10-02 | Replay guard claims a payment header for 120 s and releases it when the payment was not consumed (invalid, origin non-2xx) | KB-X402-07 duplicate_settlement rule, while letting honest retries through after an origin error | No local guard (rely on facilitator nonce rules only) |
| 2026-10-02 | Ledger is SQLite via rusqlite (bundled) with `ts` as unix-ms INTEGER, not sqlx | Boring, no async driver or migrations tooling for one table; SQLite has no timestamp type anyway. Postgres for hosted mode can come later | sqlx sqlite + postgres now |
| 2026-10-02 | Demo buyer identifies as `AgentToll-Buyer/<ver>` and the detector lists it as a self-declared agent | It must be quoted a price in agents-only mode; impersonating ClaudeBot would be dishonest | Spoof a Claude UA |
| 2026-10-02 | x402-chain-eip155 2.0.2 is built with `client,telemetry` | Upstream bug: `client` alone uses `tracing` without depending on it | Patch the crate |
| 2026-10-02 | D3 critic blocker fixed: when `/settle` fails in transit after the origin succeeded, the gateway serves the content, keeps the payment claimed and records it as `unconfirmed` | The payment may have landed; withholding content would charge without service and leave no trace (x402-protocol skill rule). Worst case the founder loses one unpaid response | Withhold content and return 502 (D3 behaviour, charged buyers could go unserved) |
| 2026-10-02 | Replay key is the canonical JSON of the payment's signed `payload`, not the raw header | Re-encoding the same payment with different whitespace bypassed a raw-header key (D3 critic risk) | Hash the raw header |
| 2026-10-02 | A payment that names `resource.url` must match the resource being requested | Stops a captured payment being spent on another route at the same price (D3 critic risk) | Match price only |
| 2026-10-02 | Facilitator timeouts are config (`timeouts.verify_ms` 5000, `timeouts.settle_ms` 20000) | Public facilitators answer slower than the skill's 2 s / 10 s draft; both stay well inside a Solana blockhash lifetime | Hard-coded constants |
| 2026-10-02 | Unpaid MCP `tools/call` gets the MCP-native challenge by default (`mcp.challenge: mcp-native`); `http-402` remains available; batches always get HTTP 402 | MCP clients read JSON-RPC results, not HTTP 402; the x402 MCP transport defines this shape (KB-X402-05) | HTTP 402 only |
| 2026-10-02 | For MCP calls a JSON-RPC error or a tool result with `isError: true` counts as an origin failure: no settlement | MCP tool errors arrive as HTTP 200; agents must not pay for a crashed tool | HTTP status only |
| 2026-10-02 | `GET /.well-known/agenttoll.json` publishes every price and payment option (AgentToll's own format, not an x402 standard) | Agents and pay-mcp can budget before calling; no x402 discovery standard was verified | No discovery |
| 2026-10-02 | Local demos use a SIMULATED facilitator (`demo/mock-facilitator`) whose settlements are `SIMULATED-*` and labelled everywhere | Joseph does not want to fund wallets yet; the demo must run end to end without ever presenting a fake payment as on-chain | Wait for funding; fake real-looking signatures (never) |
| 2026-10-02 | Payouts: no live neobank or off-ramp API during the hackathon; `pay_to` is the payout destination (wallet, stablecoin business account, or off-ramp deposit address). Bridge liquidation addresses first after the hackathon (docs/PAYOUTS.md) | All bank-touching options need KYC/KYB and run mainnet only; Bridge sandbox has no testnet (KB-PAY-*) | Integrate a neobank API now |
| 2026-10-02 | Admin API is a separate listener, off unless `AGENTTOLL_ADMIN_TOKEN` (>= 24 chars) is set; token compared in constant time | Revenue data is private; never expose it on the public port | Same port with a path prefix |
| 2026-10-02 | Paid MCP calls settle only when every paid `tools/call` id received a successful result; SSE bodies are read event by event; compressed or unreadable bodies never settle; paid MCP forwards drop `Accept-Encoding` | D4 critic blockers: an error after an SSE notification, or a gzip'd error, was settled. When in doubt the buyer is not charged | First-event SSE check; decode gzip in the gateway |
| 2026-10-02 | MCP quotes put the tool in the resource URL fragment (`/mcp#mcp:search_docs`), so a payment echoing `resource` is bound to its tool | All tools share one endpoint; a captured payment for one tool could buy another at the same price | Bind only by price |
| 2026-10-02 | `resource` in a payment stays optional (checked when present) | x402 v2 makes it optional and the TypeScript SDK's behaviour is unverified; requiring it could reject honest clients. Revisit after checking @x402/core | Require it |
| 2026-10-03 | Unsettled MCP content is returned only when every paid call provably failed (JSON-RPC error or result.isError); unverifiable 2xx results (unmatched ids, compressed, unreadable) get 502 with content withheld; numeric ids compare by value; batches with duplicate ids never settle | D4 re-review blocker: skipping settlement but serving the 2xx body gave paid tool output away for free (float id 9.0 echoed as 9, gzip, stringified ids) | Serve the body whenever settlement is skipped |
| 2026-10-02 | No neobank or off-ramp API integration during the hackathon. `pay_to` stays a founder-chosen address (self-custody wallet, stablecoin business account, or off-ramp liquidation address); cash-out is documented in docs/PAYOUTS.md; a read-only dashboard "Cash out" panel and a native "payout destinations" integration (Bridge liquidation addresses first) go on the roadmap | Every bank-touching provider needs KYC/KYB and runs mainnet only; Bridge's sandbox has no testnet and fake addresses, so nothing could show in a devnet demo (KB-PAY-01..05). Keeping AgentToll out of the money path preserves the non-custodial story. $0.002 payments hit off-ramp minimums, so the honest design is wallet in, batched sweep out (KB-PAY-07) | (a) Bridge sandbox integration now (fake addresses, cannot settle devnet USDC); (b) Stripe or Coinbase Business deposit address as default `pay_to` (needs a KYB'd account, custodial, micro-deposit crediting unverified); (c) AgentToll-operated pooled payouts (custody, money-transmitter risk) |
